# Photos for the Sarajevo "Apartment Glorija" listing (Lukavica)

Drop the apartment photos into this folder using these exact filenames.
The page picks them up automatically ~ no code changes needed. Until a file
is present, the site shows a tidy placeholder in its place.

| Filename          | What it should show                                  |
| ----------------- | ---------------------------------------------------- |
| `living-room.jpg` | The living room with the sofa + rug (this is the HERO)|
| `kitchen.jpg`     | The kitchen with the oven and breakfast bar          |
| `bedroom.jpg`     | The bedroom (double bed with the artwork)            |
| `dining.jpg`      | The breakfast bar with the two stools                |
| `bedroom-2.jpg`   | The bed seen straight on                             |
| `bathroom.jpg`    | The bathroom (corner shower)                         |

Tips:
- Use `.jpg` (or update the `src` values in `src/data/accommodations.ts`).
- If you send one more photo, save it here and add an entry to this
  listing's `images` array in `src/data/accommodations.ts`.
