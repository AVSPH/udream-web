# Photos for the Mostar "Workspace w/ Monitor" listing

Drop the apartment photos into this folder using these exact filenames.
The page picks them up automatically ~ no code changes needed. Until a file
is present, the site shows a tidy placeholder in its place.

| Filename          | What it should show                                  |
| ----------------- | ---------------------------------------------------- |
| `workspace.jpg`   | The desk with the external monitor (this is the HERO)|
| `living-room.jpg` | The living room with the big sectional sofa          |
| `balcony.jpg`     | The terrace with outdoor seating                     |
| `bedroom.jpg`     | The bedroom with the king bed                        |
| `kitchen.jpg`     | The kitchen                                          |
| `dining.jpg`      | The dining nook by the balcony door                  |
| `bathroom.jpg`    | The bathroom with the tub + washer                   |
| `entrance.jpg`    | The entry hallway / WELCOME sign                     |

Tips:
- Use `.jpg` (or update the `src` values in `src/data/accommodations.ts`).
- Landscape 4:3 or 16:10 crops look best; ~1600px wide is plenty.
- To add MORE photos later, save them here and add an entry to the `images`
  array in `src/data/accommodations.ts`.
